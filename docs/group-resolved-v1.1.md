# SpinSpec v1.1: group-resolved relative line strengths

The **group-resolved** option decomposes the SAME gamma-weighted
observation operator as the ordinary v1.1.0 mode. It does **not** model
a particular zero-field experiment. Ordinary spectra from older releases
used an equal-spin-weight observer and have different relative strengths.

## What can be separated

Group IDs are assigned to each spin in the same order as the gyromagnetic
ratios in the `.set` input file.

For a model containing three equivalent protons and one phosphorus spin,
enter `0 0 0 1` in the optional **Group-resolved spectrum** web field.

In the C command-line interface, enable the same calculation with

```sh
export SPINSPEC_OBSERVER_GROUPS=0,0,0,1
./engine_matrix "Trimethyl_phosphate (one brench).set"
```

The example in the repo describes only **one branch** of trimethyl
phosphate, i.e. a 4-spin (H3P) model; the actual molecule has **9 protons
and one phosphorus**.

For each group `g` the experimental observation operator is

```
O_g = sum_{k in g} (gamma_k/gamma_H) I_{kx}
O = sum_g O_g
```

The physical reason for grouping need not be isotope identity: one can
choose a CH3 group and a CH2 group as two groups while retaining **all**
J-couplings in the Hamiltonian.

For nondegenerate levels `i`, `j`, the line strengths satisfy

```
A_total = |sum_g <i|O_g|j>|^2
        = sum_g A_g + A_cross
A_g     = |<i|O_g|j>|^2
A_cross = 2 sum_{g<h} Re(<i|O_g|j>*<j|O_h|i>)
```

The cross contribution can have either sign. A plot of individual group
strengths must not be interpreted as an additive decomposition **unless**
this cross term is retained.

For degenerate energy levels, the export
`Sp_invariant_00000.csv` uses projectors `P_a` onto distinct energy
eigenspaces instead of an arbitrary choice of vectors in each space:

```
A_ab = Tr(P_a O P_b O), a != b
A_aa = Tr(P_a O P_a O)/2, at frequency zero
```

The DC convention is one-sided; it includes diagonal elements and obeys
`sum_{a<=b} A_ab = Tr(O^2)/2`. Block grouping uses an explicit
floating-point energy tolerance (see `observer_invariant.h`).

## Files and original graphical program

When groups are enabled, the C engine retains the legacy files and also
writes:

- `Sp_groups_00000.csv`: raw per-eigenstate transition amplitudes and
  strengths (individual terms can depend on the basis at degeneracies).
- `Sp_invariant_00000.csv`: basis-invariant contributions by pairs of
  energy eigenspaces. Includes **zero-frequency** mathematical power.
- `group_curve_00000.dat`: frequency, total Lorentzian curve, each group
  curve, **signed** interference curve.
- `group_spectrum_00000.jpg`: JPEG generated by the **C/Gnuplot**
  plotting backend. The graph deliberately excludes DC so finite J-lines
  are visible without artificial amplitude rescaling.

The ordinary graph `data_00000.jpg` uses the same gamma-weighted total
operator as the group-resolved plot, but does not show its decomposition.
Both dynamic plots omit DC; the complete projector DC convention remains
available in `Sp_invariant_*.csv`. `Res_<spin>_00000.dat` contains display
windows rather than isotope-selective observations.

The `group_graph` binary must be in the working directory alongside
`engine_matrix` and `matrix_graph`. For Linux:

```sh
gcc -O2 -fopenmp bin/engine_matrix.c -o bin/engine_matrix -lgsl -lgslcblas -lm
gcc -O2 bin/matrix_graph.c bin/GnuGraph.c -o bin/matrix_graph -lm
gcc -std=c11 -O2 bin/group_graph.c -o bin/group_graph -lm
cd bin
cp "../examples/Trimethyl_phosphate (one brench).set" example.set
SPINSPEC_OBSERVER_GROUPS=0,0,0,1 OMP_NUM_THREADS=1 ./engine_matrix example.set
```

The native plotting binary can also be called directly to replot an
existing invariant CSV, e.g. `./group_graph 0 0.2` (frame number,
Lorentzian full width at half maximum in Hz).

## Important experimental limitations

This version calculates **relative strengths of an operator**. A
zero-field or near-zero-field experimental FID requires the actual
initial density matrix, polarization direction, transfer/shuttle
protocol, field-switching and pulse sequence; detection orientation
(`M_x`, `M_y`, or `M_z`) and receiver transfer function matter.
None of these are yet part of this optional group-observer model.

At exactly zero field the idealized transverse observation model is
rotation-equivalent to the longitudinal observation model **only**
under a correspondingly rotated preparation. Relative strengths should
not be presented as experimentally calibrated amplitudes.

Scientific originality of the decomposition is **not claimed** by
the presence of this software. Comparison with previous projection,
subspace, and observable-decomposition methods is necessary for a
separate methodological publication.

## Validation

The release candidate is checked using analytical 1H-31P results,
independent NumPy Hamiltonian/projector calculations for 3-8 spin
systems, degenerate-subspace basis rotations, full sum rules, and
native C/Gnuplot output with a 0-mT H3-P model.
