Version history

Changes to the online SpinSpec simulator. Numerical strengths are relative; the current web limit is 8 spin-½ nuclei.

SpinSpec 1.2.0 November 2026

  • Faster exact diagonalization using conserved total spin projection (Mz) blocks.
  • Accelerated gamma-weighted observer transformation and transition calculations.
  • Nine-spin benchmarks: approximately 22× faster at 3 T and 49× faster at zero field in the validated benchmark environment. Speed depends on hardware and the spin system.
  • Compared with the reference engine, maximum line-frequency deviations were approximately 1.66 × 10−5 Hz at 3 T and 1.68 × 10−12 Hz at zero field; the invariant DC contribution matched.
  • Corrected magnetic-field, linewidth and automatic graph-height settings across 17 example files.
  • Improved group-panel frequency zoom, fitted to significant transitions while respecting the user-defined maximum spectrum width.
  • Input parameters and export data formats remain compatible; the public web limit remains 8 spins.

SpinSpec 1.1 November 2026

  • Optional spin-group resolved observation with a signed gamma-weighted transverse operator.
  • Group strengths, total strengths and signed interference.
  • Invariant energy-block treatment of zero-frequency (DC) components.
  • CSV exports of discrete transitions and group-resolved invariant spectra.
  • Automatic group display windows, refreshed web layout and an organized example catalog.

SpinSpec 1.0.0 Initial archived release

  • Hamiltonian construction and diagonalization for coupled spin-½ systems.
  • Transition frequencies, relative line strengths and Lorentz-broadened visual spectra.
  • Magnetic-field, chemical-shift and isotropic J-coupling inputs.
  • Permanent archive: DOI 10.5281/zenodo.23696822.

Reproducibility

For scientific use, record the software version, the full input .set file, the observation mode and the exported results. Detailed source changes and Git commits are available in the SpinSpec GitHub repository.

The online simulator does not model experimental state populations, pulse preparation or receiver response; calculated strengths are relative.
