Online NMR spectrum simulation

SpinSpec calculates transition frequencies and relative line strengths for coupled spin-1/2 nuclear systems. Explore scalar J-coupling, chemical shifts and spectral changes from high to low magnetic fields.

What SpinSpec calculates

SpinSpec constructs and diagonalizes the coupled-spin Hamiltonian. Group-resolved analysis is an optional observation mode.

Zeeman and isotropic J-coupling terms; eigenvalues, transition frequencies and relative strengths.

Spin-group contributions

Physical model and interpretation

For N coupled spin-1/2 nuclei, the Hamiltonian has dimension 2ᴺ × 2ᴺ. Transition frequencies are obtained from eigenenergies in frequency units.

νij = |Ej − Ei|
Stotal = Σg Sg + Sinterference

In group-resolved mode, the total transition strength is the sum of group strengths and their signed interference. A negative interference term is physically admissible.

Input and output conventions

Gyromagnetic ratiosOne value per spin, MHz/T; also determines the number of spins.
Chemical shiftsOne value per spin, ppm; the order must match the ratios.
External fieldMagnetic field in mT.
J-couplingsOne line per interaction: spin_i spin_j J, with J in Hz and zero-based spin indices.
Displayed spin numbersSpace-separated zero-based indices of the ordinary spectrum panels; the Hamiltonian always includes all spins.
Advanced spectrum settingsOne FWHM value and optional independent X left/right and Y lower/upper limits. Blank bounds mean automatic scaling; negative Y limits are supported.
Decimal inputBoth decimal point and decimal comma are accepted in browser fields. Separate numeric list items with spaces. Saved .set files use decimal points.
CSV exportStandard: Sp_transitions_00000.csv. Groups: Sp_invariant_00000.csv (energy blocks, group strengths, total and interference).
Scientific limitations

Plotted strengths are squared matrix elements of the signed gamma-weighted transverse observation operator, not calibrated experimental FID amplitudes. Ordinary and grouped calculations use the same operator; group mode resolves coherent contributions and signed interference in invariant energy blocks. Their CSV rows have different organizations (eigenstate pairs versus invariant energy blocks), so intensities should be compared after appropriate aggregation, not row by row. Zero-frequency DC terms are retained in the invariant CSV but not drawn as dynamic AC peaks. Thermal populations, pulse preparation, relaxation and receiver transfer functions are not modeled. Suggested spin groups are not proof of strict magnetic equivalence, and illustrative example J values require literature verification.

Automatic plotting workflow in version 1.2

Expand Advanced spectrum settings (linewidth and plot axes) to edit FWHM and optional independent axis limits. The old Graph heights and combined spectrum-width fields are no longer shown. When X/Y boundaries are blank, the renderer chooses them automatically. A display-only edit reuses previously saved transitions within the browser tab; a change of B, γ, shifts, J or observer groups requires a new diagonalization. Any server rate-limit error is shown over the spectrum preview.

With Save set and Open set you can exchange model files. Old .set width records remain supported, with positive legacy half-widths converted to explicit X boundaries on import.
