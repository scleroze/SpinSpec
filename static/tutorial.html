SpinSpec 1.2 Web Tutorial

Guide to the current calculator: model input, automatic full calculation or replot, independent axis limits, group-resolved spectra and CSV export.

Quick start · Linewidth and axes · Spin groups · Input and file formats · CSV columns and units

1. What SpinSpec does

SpinSpec calculates NMR transition frequencies and relative strengths from a coupled spin-1/2 Hamiltonian, using gyromagnetic ratios, chemical shifts, magnetic field and isotropic J-couplings. It covers conventional fields, weak fields and zero field. The public web calculator supports systems of up to eight spin-1/2 nuclei.

The current page has a parameter form on the left and the spectrum preview on the right (stacked on small screens). One Calculate spectrum button automatically selects a full calculation or a faster redraw from saved transitions. Calculation errors and request-limit warnings appear over the preview.

The current input convention uses spin numbers starting from 0. For example, in a six-spin system the spins are numbered 0 1 2 3 4 5.

2. Quick start: examples and one calculation button

  1. Open the calculator and select a model from Examples. Examples are grouped by category; illustrative and reduced models are identified in the list.
  2. Selecting an example fills the form and starts its calculation automatically. The ordinary spectrum appears in the right-hand preview.
  3. Change a display setting, such as Line width (FWHM, Hz), under Advanced spectrum settings (linewidth and plot axes).
  4. Press Calculate spectrum. The hint below the button indicates whether SpinSpec will redraw cached transitions or recalculate the Hamiltonian.
  5. Optionally enable Calculate contributions of spin groups to display separate group strengths and signed interference.
Two automatic paths: changing only FWHM, X/Y boundaries or displayed windows preserves calculated transition data. Changing the field, γ values, shifts, J-couplings or group assignments requires a full calculation. Fast replot needs a previous compatible job in the same browser tab.

3. Input fields

Title

A short name for the calculation. It is stored in the .set file. The title may start with #.

Gyromagnetic ratios (MHz/T)

One number for each spin. The number of values defines the number of spins in the system.

Chemical shifts (ppm)

One chemical shift value for each spin, in the same order as the gyromagnetic ratios.

External field (mT)

The static magnetic field used in the Hamiltonian calculation. Enter a single value for one spectrum.

J-couplings

Each line has the format spin_i spin_j J, where J is given in Hz.

Displayed spin numbers

Spin indices for which spectra should be plotted.

Vertical intensity scale

Automatic by default. The old Graph heights input has been removed. Open Advanced spectrum settings to enter optional independent lower and upper Y limits; negative interference remains visible when the bounds are automatic.

Line width (FWHM, Hz)

Enter one positive FWHM value. Spectrum windows are fitted automatically; use the independent X boundary fields in Advanced spectrum settings if manual limits are needed. The legacy .set format still stores two numbers, with the second set to 0 for automatic scaling.

4. Gyromagnetic ratios

Enter gyromagnetic ratios in MHz/T, separated by spaces. For convenience, the expandable isotope list gives typical values.

Click an isotope value in the expandable list to insert it directly into the Gyromagnetic ratios (MHz/T) field at the cursor position. No clipboard paste is needed.

For example, a system with five protons and one phosphorus nucleus may be entered as:

42.578 42.578 42.578 42.578 42.578 17.24

5. Where to find chemical shifts and J-couplings

Chemical shifts and scalar J-coupling constants can be taken from experimental NMR databases, spectral tables, or original literature. Always check the solvent, reference compound, temperature, and nucleus, because these parameters may affect the reported values.

Organic Chemistry Data / Hans Reich NMR tables

Practical tables for common 1H, 13C, 19F, and 31P chemical shifts and J-coupling ranges.

organicchemistrydata.org

SDBS, AIST

Free spectral database for organic compounds, including 1H-NMR and 13C-NMR spectra for many molecules.

sdbs.db.aist.go.jp

nmrshiftdb2

Open NMR database with assigned spectra, peak lists, and prediction tools for organic structures.

nmrshiftdb.nmr.uni-koeln.de

NIST Chemistry WebBook

Reference chemical database from NIST. It is useful for identifying compounds and checking available physical and spectral data.

webbook.nist.gov

Original articles and handbooks

For specialized nuclei such as 31P, or for low-field and zero-field simulations, original papers and dedicated NMR handbooks are often the most reliable source of J-couplings.

Use experimental values when possible. Predicted values are useful for a first test, but they should be marked as estimates.

6. Chemical shifts and magnetic field

Chemical shifts are entered in ppm, one value per spin. The order must exactly match the order of gyromagnetic ratios.

Normally the external field is entered in mT. For example:

500

Alternatively, check enter as ¹H frequency (MHz) and enter one nominal proton Larmor frequency. The browser converts it to mT before calculation and when saving a .set file.

7. J-couplings

The J-couplings field describes scalar spin-spin interactions. Each line contains two spin indices and the coupling constant in Hz:

Only one direction is required. For example, enter 0 5 0.9 or 0 5 0,9; the coupling is symmetric. Separate the two spin indices and J value with spaces. Decimal commas are converted to dots before computation.

8. Choosing the displayed spectra

Displayed spin numbers is a space-separated list of zero-based indices, for example 0 3 5. It determines the ordinary spectrum panels, not which spins enter the Hamiltonian.

Every panel initially uses automatic vertical scaling. There is no Graph heights field in version 1.2. Enter a Y minimum or maximum only when you need a particular range. In group-resolved mode, SpinSpec automatically selects a reference window for each nonempty observer group.

9. Line width, spectral window, and calculation

The FWHM is now a separate numeric field under Advanced spectrum settings. The horizontal window is automatic until the user supplies one or both X boundaries.

Press Save set to store the current input, Open set to load an existing file, or Calculate spectrum to run the Hamiltonian calculation and generate the plotted spectra.

Calculate spectrum automatically chooses between full Hamiltonian diagonalization and fast plotting from saved transition frequencies, strengths and invariant DC contributions. Changing FWHM, X or Y bounds, or displayed spin windows needs only plotting; changing magnetic field, gyromagnetic ratios, chemical shifts, J-couplings or observer-group assignments triggers a full calculation. This also applies after opening a modified .set file, provided the previous calculation is available in the current browser session. A hint beneath the button shows which path will run. Jobs from older software versions without cache metadata are recalculated.

10. Spin-group spectra: setup and interpretation

Enable Calculate contributions of spin groups under Group-resolved spectrum (optional). SpinSpec retains all spins in the Hamiltonian, even when only selected group panels are displayed. The groups partition the observation operator; they do not remove J-couplings or change the calculated eigenenergies.

Choosing groups in the web interface

  1. Load a model, such as Fluoroethane, from Examples.
  2. Enable Calculate contributions of spin groups. The application proposes group assignments using approximate gyromagnetic ratios, chemical shifts and patterns of J-couplings.
  3. Check the Group 0 / Group 1 / ... selectors next to each spin. These are suggestions, not a proof of strict magnetic equivalence.
  4. Choose Auto-detect groups to regenerate the suggestions after editing the spin model, or Separate all spins to assign one group to every spin.
  5. Use the selectors to combine or split groups manually. Alternatively expand Advanced: edit group IDs and enter one integer (0–9) per spin in spin order.
  6. Press Calculate spectrum. A second image shows each group's strength, the full strength and the signed interference. The invariant CSV can be downloaded below it.
Fluoroethane example: six spins indexed 0 1 2 3 4 5. Enter 0 0 0 1 1 2 in the advanced group-ID field to assign CH3 protons (0–2) to group 0, CH2 protons (3–4) to group 1, and the 19F spin (5) to group 2. IDs identify observation components, not chemical elements.

What the colored curves mean

The observation operator used in both ordinary and group modes is a signed gamma-weighted transverse spin operator. For spin group g, let O_g = sum_(k in g) (gamma_k / gamma_H) I_kx; the complete operator is O = sum_g O_g. For a transition, each group contributes a real amplitude D_g and strength |D_g|^2. Their coherent sum gives

Stotal = Σg Sg + Sinterference

Sinterference collects cross terms of group amplitudes. It may be positive or negative; the total transition strength remains non-negative.

In the plot the thick colored line is the selected group, the thin gray line is Total, and the cyan line is Interference. The Total overlay is repeated in each local window for comparison; it is not an additional independent group. Negative interference indicates cancellation between amplitudes, not negative measured absorption.

Invariant DC: numerically degenerate energy states can contribute at 0 Hz. The group CSV includes the invariant zero-frequency contribution; the dynamic group curves do not draw it as an AC peak. See CSV export for definitions and the exact sum rule.

Scientific limitation: these are relative squared operator matrix elements. The model does not include spin populations, pulse preparation, relaxation, receiver transfer functions, or calibrated experimental signal intensities. Assigning a group is an analysis choice, not a claim that it can be measured independently.

11. Additional settings and display controls

Decimal separators: SpinSpec accepts both 0.25 and 0,25 in browser input fields, including FWHM, X/Y limits, gyromagnetic ratios, shifts, magnetic field and J-couplings. For numeric lists, put spaces between values: 42,577 17,235. An ambiguous string such as 42,577,17,235 is rejected. Files saved by SpinSpec always use a decimal point to preserve compatibility with the C engine and the traditional .set format.

13. Common checks

  • The number of gyromagnetic ratios must equal the number of chemical shifts.
  • Spin indices in J-couplings must refer to existing spins.
  • The number of graph-height values should match the number of displayed spin numbers.
  • Use spaces between numbers. Avoid commas as decimal separators.
  • Use Hz for J-couplings and mT for the magnetic field.

14. Interactive mode

After a spectrum has been calculated, the standard preview image is shown in the main window. To inspect the spectrum in more detail, click the Interactive mode button above the preview. The interactive spectrum opens in a new browser tab.

In interactive mode, the spectrum can be moved and zoomed with the mouse. Use the mouse wheel to zoom, drag the plot to pan, or use the Plotly toolbar in the upper-right corner of the graph.

Spectral lines are automatically grouped into frequency regions. The buttons above the graph, such as Full spectrum and Group 1, allow quick navigation between groups of lines. When a group is selected, the graph is automatically zoomed to the corresponding frequency range.

The Line width field controls the Lorentzian line-width parameter used only for interactive visualization. Changing this value and pressing Redraw recalculates the displayed line shapes without repeating the Hamiltonian calculation.

Interactive mode uses the calculated line frequencies and amplitudes from the spectrum data file. It is intended for convenient inspection of peaks, multiplets, and closely spaced spectral features.

15. Exporting numerical transition data (CSV)

After pressing Calculate spectrum, expand Export numerical transition data (CSV) below the plot. The exported file follows the selected calculation mode. A CSV file stores discrete transition positions and strengths before Lorentzian broadening. The numbers are relative model strengths, not measured NMR intensities.

Ordinary spectrum — Sp_transitions_00000.csv

One row represents an unordered pair of Hamiltonian eigenstates. The file is a documented four-column export of the legacy Sp_00000.dat output.

ColumnMeaning
state_i, state_jEigenstate indices, numbered from 1 (the diagonalizer's order is not an energy ranking)
frequency_hzAbsolute transition frequency |Ej - Ei|/h, in Hz
relative_strengthSquared matrix element of the signed gamma-weighted transverse observation operator; relative units
 
state_i,state_j,frequency_hz,relative_strength
1,2,2128.400000,0.250000
1,3,2131.200000,0.500000

Numbers in the example above are illustrative, not a particular molecule. The current engine writes full-precision numerical transition values.

Group contributions — Sp_invariant_00000.csv

One row represents a pair of distinct or identical energy blocks, where each block contains numerically degenerate Hamiltonian eigenstates. The result is invariant under rotations of eigenvectors within a degenerate block. Group IDs are taken from the spin-group selector.

ColumnMeaning
block_a, block_bZero-based indices of energy blocks sorted by energy
dim_a, dim_bNumber of eigenstates in each block
energy_a_hz, energy_b_hzBlock energies expressed as E/h (Hz); only differences are physical frequencies
frequency_hzNon-negative transition frequency between blocks, in Hz
total_strengthStrength for the combined, gyromagnetically weighted observation operator
interferenceSigned cross contribution between groups; can be negative
strength_g0, strength_g1, ...Individual group strengths for group IDs 0, 1, ...

For each CSV row: total_strength = strength_g0 + strength_g1 + ... + interference. In this model the group observation operator is proportional to sum_k (gamma_k/gamma_H) I_kx with spins partitioned by group ID. Thus group strengths alone need not add up to the total.

Rows with frequency_hz = 0 are retained in the invariant CSV, but the plotted dynamic group spectrum omits this DC contribution. The ordinary and group modes use the same gamma-weighted observation operator. Their exported rows are organized differently (eigenstate pairs versus invariant energy blocks), and numerical strengths should be compared after appropriate frequency or energy-block aggregation, not by state labels. Neither export includes thermal level populations, excitation/preparation, relaxation, receiver response or absolute experimental signal calibration.

Interpretation: The choice of Displayed spin numbers selects frequency windows for plotting, not a restriction on which spins enter the Hamiltonian or CSV. A local frequency offset on the plot is the absolute transition frequency minus the window's reference NMR frequency.
