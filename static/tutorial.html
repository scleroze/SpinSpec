SpinSpec Web Tutorial

A short guide to entering spin-system parameters and calculating Hamiltonian-based NMR spectra in the SpinSpec web interface.

1. What SpinSpec does

SpinSpec calculates NMR spectra from a spin Hamiltonian. The input describes a set of spin-1/2 nuclei, their gyromagnetic ratios, chemical shifts, external magnetic field, and scalar J-couplings. After calculation, the program builds spectra for selected observed spins.

The current input convention uses spin numbers starting from 0. For example, in a six-spin system the spins are numbered 0 1 2 3 4 5.

2. Starting from an example

The easiest way to begin is to choose one of the prepared examples from the Examples list.

After selection, SpinSpec fills the input fields automatically. You can then edit any parameter manually.

3. Input fields

Title

A short name for the calculation. It is stored in the .set file. The title may start with #.

Gyromagnetic ratios (MHz/T)

One number for each spin. The number of values defines the number of spins in the system.

Chemical shifts (ppm)

One chemical shift value for each spin, in the same order as the gyromagnetic ratios.

External field (mT)

The static magnetic field used in the Hamiltonian calculation. Enter a single value for one spectrum.

J-couplings

Each line has the format spin_i spin_j J, where J is given in Hz.

Displayed spin numbers

Spin indices for which spectra should be plotted.

Graph heights

Vertical scale for each displayed spectrum. The number of values should match the number of displayed spins.

Line width and spectrum width (Hz)

The first number is the Lorentzian line-width parameter. The second number is the displayed spectral window half-width in Hz.

4. Gyromagnetic ratios

Enter gyromagnetic ratios in MHz/T, separated by spaces. For convenience, the expandable isotope list gives typical values.

When you click a gyromagnetic-ratio value in the isotope list, the value is automatically copied to the clipboard. You can then paste it into the required position in the Gyromagnetic ratios input field.

For example, a system with five protons and one phosphorus nucleus may be entered as:

42.578 42.578 42.578 42.578 42.578 17.24

6. Where to find chemical shifts and J-couplings

Chemical shifts and scalar J-coupling constants can be taken from experimental NMR databases, spectral tables, or original literature. Always check the solvent, reference compound, temperature, and nucleus, because these parameters may affect the reported values.

Organic Chemistry Data / Hans Reich NMR tables

Practical tables for common 1H, 13C, 19F, and 31P chemical shifts and J-coupling ranges.

organicchemistrydata.org

SDBS, AIST

Free spectral database for organic compounds, including 1H-NMR and 13C-NMR spectra for many molecules.

sdbs.db.aist.go.jp

nmrshiftdb2

Open NMR database with assigned spectra, peak lists, and prediction tools for organic structures.

nmrshiftdb.nmr.uni-koeln.de

NIST Chemistry WebBook

Reference chemical database from NIST. It is useful for identifying compounds and checking available physical and spectral data.

webbook.nist.gov

Original articles and handbooks

For specialized nuclei such as 31P, or for low-field and zero-field simulations, original papers and dedicated NMR handbooks are often the most reliable source of J-couplings.

Use experimental values when possible. Predicted values are useful for a first test, but they should be marked as estimates.

6. Chemical shifts and magnetic field

Chemical shifts are entered in ppm, one value per spin. The order must exactly match the order of gyromagnetic ratios.

The external field is entered in mT. For example:

500

7. J-couplings

The J-couplings field describes scalar spin-spin interactions. Each line contains two spin indices and the coupling constant in Hz:

0 3 7.1
1 3 7.1
2 3 7.1
0 5 0.9
1 5 0.9
2 5 0.9
3 5 8
4 5 8
Only one direction is required. For example, write 0 5 0.9; the program treats the coupling as symmetric.

8. Selecting displayed spectra

Use Displayed spin numbers to choose which nuclei should be shown in the final plot.

The Graph heights field controls the vertical scale of each plotted spectrum. The order follows the displayed spin numbers.

9. Line width, spectral window, and calculation

The final field contains two numbers:

ValueMeaningExample
Line widthLorentzian line-width parameter used to draw peaks.0.05
Spectrum widthHalf-width of the displayed spectrum around the central NMR frequency.20

Press Save set to store the current input, Open set to load an existing file, or Calculate spectrum to run the Hamiltonian calculation and generate the plotted spectra.

11. Common checks

  • The number of gyromagnetic ratios must equal the number of chemical shifts.
  • Spin indices in J-couplings must refer to existing spins.
  • The number of graph-height values should match the number of displayed spin numbers.
  • Use spaces between numbers. Avoid commas as decimal separators.
  • Use Hz for J-couplings and mT for the magnetic field.

Interactive mode

After a spectrum has been calculated, the standard preview image is shown in the main window. To inspect the spectrum in more detail, click the Interactive mode button above the preview. The interactive spectrum opens in a new browser tab.

In interactive mode, the spectrum can be moved and zoomed with the mouse. Use the mouse wheel to zoom, drag the plot to pan, or use the Plotly toolbar in the upper-right corner of the graph.

Spectral lines are automatically grouped into frequency regions. The buttons above the graph, such as Full spectrum and Group 1, allow quick navigation between groups of lines. When a group is selected, the graph is automatically zoomed to the corresponding frequency range.

The Line width field controls the Lorentzian line-width parameter used only for interactive visualization. Changing this value and pressing Redraw recalculates the displayed line shapes without repeating the Hamiltonian calculation.

Interactive mode uses the calculated line frequencies and amplitudes from the spectrum data file. It is intended for convenient inspection of peaks, multiplets, and closely spaced spectral features.
